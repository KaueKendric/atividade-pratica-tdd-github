# Atividade prática de TDD

Aluno: Kauê Kendric Loureiro da Costa, 10° semestre engenharia da computação

Atividade de Engenharia de Software com três desafios em TypeScript e Vitest.

## Executar

Requisito: Node.js 22.12 ou superior, com npm.

```bash
npm ci
npm test
npm run typecheck
```

## Desenvolvimento

O projeto está sendo desenvolvido com testes escritos e executados antes da implementação.
Os registros reais de execução ficam em `evidencias/`. Cada ciclo será registrado em commits separados.
